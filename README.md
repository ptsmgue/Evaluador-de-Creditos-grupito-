# Evaluador-de-Creditos-grupito-
## Como ejecutar el programa
- Paso 1: Ejecute el script de la base de datos. https://drive.google.com/file/d/118TXt8j8qm4up_9zNcP1MWLc4sy_hlnx/view?usp=sharing
- Paso 2: Descargue la carpeta. El proyecto está dentro de la carpeta Evaluador-de-Creditos-GUI/Evaluador-de-Creditos-grupito--main/evaluadorCrediticio/src/main/java/com/mycompany/evaluadorcrediticio
- - El ejecutable principal del proyecto se encuentra en el archivo EvaluadorCrediticio.java
- Paso 3: Entre a la clase ConexionBDD.java y modifique las credenciales de la base de datos. Dichas credenciales se encuentran en las lineas:
            server = "localhost:3306";
            bdd = "evaluadorcrediticio";
            user = "alumno";
            pwd = "12341234";
            url = "jdbc:mysql://" + server + "/" + bdd
                    + "?serverTimezone=UTC&useSSL=false&allowPublicKeyRetrieval=true&connectTimeout=5000";
